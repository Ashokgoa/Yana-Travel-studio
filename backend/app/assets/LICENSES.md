# Bundled assets

| Folder | Source | Licence |
|---|---|---|
| `maps/europe.json` | [Natural Earth](https://www.naturalearthdata.com/) 1:50m Admin 0 – Countries, clipped to Europe and simplified (coordinates rounded to 0.01°) | Public domain |
| `flags/*.svg` | [flag-icons](https://github.com/lipis/flag-icons) 7.2.3, 4×3 variants for countries on the map plus a few common source markets | MIT, © 2013 Panayiotis Lipiridis |
| `fonts/*.woff2` | Playfair Display and Inter (latin subset) from [Fontsource](https://fontsource.org/) 5.1.0 | SIL Open Font License 1.1 (see `fonts/LICENSE-*.txt`) |

These files make the PDF route maps and flags work offline (no map tiles or web fonts are fetched).
