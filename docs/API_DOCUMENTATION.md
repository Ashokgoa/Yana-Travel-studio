# API Documentation

Interactive, always-current docs are generated by FastAPI:

- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc
- OpenAPI JSON: http://localhost:8000/openapi.json

Base path: `/api/v1`. JSON only. Configure the frontend base URL with `NEXT_PUBLIC_API_BASE_URL`.

## Error format

Every non-2xx response returns:

```json
{ "error": "validation_error", "message": "Some fields are invalid.",
  "details": [{ "field": "email", "message": "value is not a valid email address" }] }
```

| `error` | HTTP | When |
|---|---|---|
| `validation_error` | 422 | Request body or query is invalid (`details` lists fields) |
| `domain_error` (or specific code) | 400/404/409 | Business rule violated |
| `http_error` | 4xx | Not found, method not allowed, … |
| `internal_error` | 500 | Unexpected failure (details in server log) |

## Endpoints

### System

| Method | Path | Description |
|---|---|---|
| GET | `/api/v1/health` | Status of API, database (with migration revision), upload storage and exports folder. `status` is `ok` or `degraded` |

Example response:

```json
{
  "status": "ok", "app_name": "YANA Travel Studio", "version": "0.1.0", "environment": "development",
  "database": { "status": "ok", "detail": "sqlite, migration 0001" },
  "storage": { "status": "ok", "detail": "writable directory available" },
  "exports": { "status": "ok", "detail": "writable directory available" }
}
```
